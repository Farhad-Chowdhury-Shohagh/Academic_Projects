# Grilli Restaurant Website

## Project Overview

Grilli Restaurant Website is a modern and responsive restaurant website developed as a Software Engineering course project. This website is designed to present restaurant information, food items, special dishes, events, reservation options, and contact details in a clean and user-friendly way.

The main goal of this project is to create an attractive frontend website where users can easily explore restaurant details, view menu items, and interact with different sections of the website through a smooth browsing experience.

## Project Modules

### 1. Header Section

The header section contains the website logo, navigation menu, and important action buttons. It allows users to easily move between different sections of the website.

### 2. Hero Section

The hero section introduces the restaurant with attractive images, title text, and call-to-action buttons. This section helps create the first impression of the website.

### 3. About Section

The about section provides information about the restaurant, food quality, services, and customer experience.

### 4. Menu Section

The menu section displays food items with images, names, descriptions, and prices. It helps users explore available dishes.

### 5. Special Dish Section

This section highlights a special or popular dish of the restaurant. It is used to attract customer attention to featured food items.

### 6. Reservation Section

The reservation section allows users to view booking-related information and restaurant contact details for table booking.

### 7. Events Section

The events section displays restaurant events, offers, or special programs.

### 8. Footer Section

The footer includes contact details, opening hours, social links, and other useful information.

## How to Run the Project Locally

## How the Website Works

The website works as a static frontend project. The structure of the website is created using HTML. CSS is used to design the layout, colors, fonts, spacing, and responsiveness. JavaScript is used to add interactive behavior such as menu toggling, button actions, scrolling effects, and dynamic user interface interactions.

When a user opens the website, the browser loads the HTML file first. Then CSS styles are applied to make the website visually attractive. JavaScript runs in the browser to make the website interactive.
